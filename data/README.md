# data

sample course materials and intermediate pipeline outputs.

## files

| file | description |
|------|-------------|
| `Big data - NOSQL Overview__.pdf` | sample course pdf used for initial indexing |
| `extracted_chunks.json` | text chunks extracted from the pdf by `extract_data.py` |
| `chunks_with_embeddings.json` | same chunks with 384d vector embeddings added by `generate_embeddings.py` |

these files are generated by the offline data pipeline scripts in `backend/`. they are not required if you use the web upload feature instead.
